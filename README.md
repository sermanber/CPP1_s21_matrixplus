# s21_matrix+

Реализация библиотеки s21_matrix_oop.h

## Introduction

В данном проекте реализована библиотека для работы с матрицами. Объектно-ориентированный подход 
позволяет реализовать библиотеку для работы с матрицами в виде отдельного класса, над объектами 
которого определены операции, представленные как методами, так и стандартными операторами +, -, * и т. д.

## Реализация функции библиотеки s21_matrix_oop.h

- Программа разработана на языке C++ стандарта C++20 с использованием компилятора gcc.
- Код программы находится в папке src.
- Стилистика кода - Google Style.
- Матрица реализована в виде класса `S21Matrix`.
- Класс хранит только приватные поля `matrix_`, `rows_` и `cols_`.
- Реализован доступ к приватным полям `rows_` и `cols_` через accessor и mutator. При увеличении размера
  матрицадополняется нулевыми элементами, при уменьшении лишнее просто отбрасывается.
- Решение оформлено как статическая библиотека (с заголовочным файлом s21_matrix_oop.h).
- Реализованы основные операции над матрицами(транспонирование. сложение, вычитание. умножение и тд.)
- Реализована перегрузка операторов +, -, * и тд.
- Полное покрытие unit-тестами функций библиотеки c помощью библиотеки GTest.
- Для сборки библиотеки и тестов предусмотрен Makefile (с целями all, clean, test, s21_matrix_oop.a).
